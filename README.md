# Swiggy-Sales-Analysis
Swiggy Sales Analysis and Interactive Excel Dashboard
**Project Overview**
This project focuses on analyzing Swiggy sales data using Microsoft Excel. The objective is to understand sales performance, customer preferences, retrurant performance, and business trends through an iteractive dashboard.

**Tool & Technologies**
> Microsoft Excel
> Pivot Tables
> Pivot Charts
> Excel formulas
> Data Cleaning
> Data Visualization
> Slicers and Interactive Filters

**Project Structure**
The Excel workbook contain multiple worksheets:
1. Raw Data-Original dataset.
2. Dashboard- Interactive visual representation of the fildings.
3. Sales Analysis- Key sales calculation ,insights and pivot tables for business analysis

**Key Performance Indicators (KPIs)**
> Total Sales
> Total Orders
> Average Order Value
> Restaurant Performance
> Customer Preferences

**Key Objectives**
> Analyze overall sales performance.
> Identify popular food categories.
> Understand customer ordering patterns.
> compare restaurant performance.
> Present business insights through an interactive dashboard.

**Conclusion**
The Swiggy Excel Dashboard provides a structured view of sales performance and customer ordering patterns. It helps transform raw data into meaningful business insights and supports data-driven decision-making.
